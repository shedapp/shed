# DentalOPG-1550 — data licence

The images and labels in this folder are a rescaled, renamed copy of DentalOPG-1550 (Chowdhury SH, Arman MS; Mendeley Data V3, doi:10.17632/rtt726b26d.3), licensed CC BY 4.0. Attribution is required. File names were changed because the originals contained patient names; only the age was kept. The FDI numbers in full_manifest.json are PanoramIA estimates, not part of the source.
