# EARS

Big ears, built daily.

An ear-training tutor for serious musicians, built on the public outline of Berklee's Ear Training 1–4 and Harmonic Ear Training. Eight modules — intervals, scale degrees, melodic dictation, chord quality, scales & modes, Roman-numeral progressions, rhythm and singing — across five levels (Major, Minor, Modes, Chromatic, Harmonic). Every interval, degree, chord, Roman-numeral token and rhythm cell is a spaced-repetition card; the app tracks what you confuse and drills exactly those pairs. The Sing module checks every note against the mic with coach-style feedback. Perfect-pitch students get an anti-absolute mode (every question slightly detuned, so letter names can't help).

**Live app:** https://shedapp.github.io/shed/ears/

Install on a phone: open the link, then iPhone → Share → *Add to Home Screen*; Android → Chrome menu → *Install*.
Keyboard: `space` replay · `1–9` answer · `↵` next · `k` hear the key.

## For teachers

Me → Teacher tools builds an assignment code (modules, levels, number of questions, due date). Students paste it under Today → *Enter assignment code*; when they finish, the app returns a result code with accuracy, time and weak items that you decode in the same place. Progress → *Copy report* gives a plain-text summary per student.

## How it is built

`index.html` is the whole app, one self-contained file. The source lives in `src/`:

- `src/theory.js` – notes, intervals, solfege (Do-based / La-based / numbers), scales, chords, Berklee Roman-numeral tokens, voicing with least-motion voice leading
- `src/audio.js` – the Salamander grand (shares Shed's samples in `../piano/`, three dynamic layers), synthesized electric piano / pad / pure tone for timbre variety, scheduler, click and rhythm voice
- `src/notation.js` – SVG rhythm engraver (beams, flags, rests, dots, ties, tuplets, time signatures, beat numbers) and the keyboard drawing
- `src/rhythm.js` – rhythm cells, meters from 2/4 to 11/8, pattern generation, distractors, tap scoring
- `src/gen.js`, `src/genrhythm.js` – the exercise generators for every module and level
- `src/srs.js` – state, FSRS-style spaced repetition, confusion tracking, mastery, session builder, reports
- `src/pitch.js`, `src/sing.js` – microphone pitch detection, note segmentation, singing tasks and evaluation
- `src/app.js`, `src/index.template.html`, `src/styles.css` – the app
- `src/test_engine.js` (node) and `src/test_browser.js` (Playwright, serves the repo over HTTP so the piano loads) – checks you can run with `node`

Rebuild with `node src/build.js` (writes `index.html`, `sw.js` and `dist/artifact.html`, the preview build with a synthesized piano).
Nothing leaves the device: exercises, scoring, pitch detection and progress all run in the browser. Progress is stored on the device and can be exported and imported from the Progress tab.

Levels mirror the public Berklee course descriptions; every exercise is generated by the engine, so no course material is reproduced. Piano samples: Salamander Grand Piano V3 (CC BY 3.0), see `../piano/CREDITS.md`.
