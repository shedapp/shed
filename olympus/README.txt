Olympus — training app (web app for iPhone/Android)

Files:
  index.html           the app page
  app.js               the app (program, 3D demos, logging, run timer, nutrition, settings)
  three.min.js         three.js r152, unmodified, from github.com/mrdoob/three.js tag r152
                       sha256 218b9f9420af1ee2b773fa066cee0eeb52f7ac76ca2fa11b11b732c1ba0a6e39
  sw.js                offline cache so the app opens without signal
  manifest.webmanifest app name/icon for Add to Home Screen
  icon-180.png / icon-360.png

Install:
  1. Upload this whole folder to a GitHub repository (keep the files together) and turn on GitHub Pages.
  2. Open the Pages address in Safari on the phone.
  3. Share -> Add to Home Screen.

Data stays on the phone (Settings -> Export JSON for a backup). AI features and sync run only in the Claude-hosted version.
